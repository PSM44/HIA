01.00 PURPOSE
WHOAMI is a generated human-readable projection explaining:
- what the project is;
- why it exists;
- what is happening now;
- what was completed;
- what remains;
- what to do next.

02.00 AUTHORITATIVE SOURCES
WHOAMI derives from:
- PROJECT.IDENTITY;
- CURRENT_STATE;
- approved decisions;
- current evidence status.

03.00 NON-AUTHORITY RULE
WHOAMI is not:
- an independent source of truth;
- a manually maintained active state;
- a replacement for CURRENT_STATE;
- a replacement for BATON;
- a replacement for detailed registers.

04.00 REQUIRED OUTPUT
A generated WHOAMI should show:
- project ID and name;
- purpose;
- scope summary;
- current focus;
- last valid progress;
- completed and pending work;
- blockers and risks;
- next action;
- evidence confidence;
- generated time;
- source references.
